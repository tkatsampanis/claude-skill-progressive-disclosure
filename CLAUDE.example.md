# Claude Code Global Configuration — Example

This file demonstrates how global instructions can work with a generated
skill catalog. Adapt it to your own setup; do not replace your personal
configuration without reviewing it first.

## Skill Discovery

- Keep the global skill catalog compact.
- Do not copy every skill's complete instructions into this file.
- When a task matches a skill's purpose, inspect that skill's `SKILL.md`
  and follow its applicable instructions.
- Use multiple complementary skills when appropriate.
- For unrelated tasks, proceed without unnecessarily consulting
  specialized skill documentation.
